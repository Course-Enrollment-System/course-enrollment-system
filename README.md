Course Enrollment System

A backend system for managing Course enrollment.

About:

The Course Enrollment System allows admin to manage courses while students can browse and enroll in available courses.

The project is built using Python, FastAPI, SQLAlchemy, and Pydantic.

Features:

Admin

- Admin registration and login
- Create courses
- View courses
- Delete courses

Student

- Student registration and login
- View available courses
- Enroll in courses
- View enrolled courses
- Drop enrolled courses

Authentication & Authorization

- Student and Admin roles
- Login/logout functionality
- Role-based access control
